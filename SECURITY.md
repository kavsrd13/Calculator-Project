# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please do NOT open a public issue for security problems.

Instead, email us at security@example.com with:
- A description of the problem
- Steps to reproduce it
- The possible impact
